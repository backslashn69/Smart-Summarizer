#**Smart Summarizer**

An AI-powered web application that helps users instantly summarize long form text using Large Language Models.

#**Features**

Three summary modes — Quick, Detailed and Bullet Points
Real time word count metrics showing original vs summary length
Percentage reduction display showing how much text was condensed
Clean simple interface built for speed and ease of use

#**Tech Stack**

Python
Streamlit
Groq API
LLaMA 3.3 70B

#**Use Cases**

Summarizing research papers and academic content
Condensing news articles and reports
Quickly extracting key points from long documents
